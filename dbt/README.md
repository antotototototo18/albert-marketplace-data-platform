# dbt

The detailed L05-L06 project steps require the dbt project in `transform/`.
Use that directory when implementing the models; this template folder is only
a pointer, so the group does not maintain two dbt projects.

Arrives in **L05 · dbt and the medallion pattern**: the silver and gold models,
their tests, source freshness checks and documentation.

In **L06** the dbt runner gets its Dockerfile here. In **L10** the PII-redaction
model joins it.
