Glossary

Every word we use, in one line.

ADR · architecture decision record: one page per choice

Bronze · raw copy of the data, exactly as it arrived

Silver · cleaned data: types fixed, duplicates removed

Gold · tables the business and data scientists read

GCS · Google Cloud Storage, where raw files live

BigQuery · Google’s database for analysis

dbt · tool that builds and tests tables with SQL

Airflow · DAG · scheduler, and its list of steps in order

Back-fill · re-running the pipeline for past days

Idempotent · running it twice gives the same result

Terraform · cloud setup written as code

Policy tag · label on a column that decides who reads it

GiB · TiB · about 1 gigabyte · about 1,000 gigabytes

DLQ · dead-letter queue: where broken events wait

PII · GDPR · personal data · the EU law that protects it

ML · machine learning, the data science team

Not presented. Show it only if a word causes confusion during questions.
