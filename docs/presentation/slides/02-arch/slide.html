COLIN, 2 min. Here is the platform, from left to right. One: where the data comes from. The shop database, the clicks on the website, and an old export of 27 tables. Two: the raw copy. We call it bronze. It is the data exactly as it arrived, stored as files in Google Cloud Storage. We keep it so we can always rebuild everything from it. Two rules apply here: passwords and card numbers never get in, and broken click events are put aside in a separate folder instead of stopping the pipeline. Three: the clean tables, in BigQuery, Google's database for analysis. A tool called dbt cleans the data, that's silver, and then builds gold, the tables the business reads. Gold includes the daily table for the data science team. This is also where each order is finally counted once, so revenue is right. Four: running it. Airflow runs the whole pipeline every day. Terraform describes our cloud setup as code, so we can rebuild it. And every column has a label that says how sensitive it is. Behind each step there is a short written decision. We call it an ADR, an architecture decision record. We wrote ten. We will not go through all of them: we picked two. HANDOVER: Benjamin, the first one: how we pay for BigQuery.
