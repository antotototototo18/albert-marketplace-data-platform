# Présentation du projet — groupe 6

Deck de 14 slides qui résume le projet de L01 à L10 : une slide par étape,
avec la personne qui l'a menée et un résultat vérifiable.

- **Sources :** `deck.json` (ordre des slides), `deck.css` (style commun) et
  `slides/NN-id/slide.html`. Les notes de l'orateur sont dans le `<aside>` de
  chaque slide.
- **Script oral :** un `README.md` par slide dit qui parle, le message clé, ce
  qu'il faut dire et où trouver la preuve si on nous la demande.

## Qui parle

Proposition à valider en PR : chaque personne présente l'étape qu'elle a menée,
d'après les auteurs des commits sur `main`. Colin présente l'architecture pour
que tout le monde parle. Compter environ une minute par slide, donc 15 minutes.

## Règle pour les chiffres

Chaque chiffre affiché vient d'un fichier du dépôt, cité dans le README de la
slide. Si un chiffre change, corriger d'abord le document source, puis la slide.
Les chiffres ont été vérifiés le 20 novembre 2026.
